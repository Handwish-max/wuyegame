# 猫猫便利店 · Midnight Paws

一个以午夜便利店为灵感、加入小动物顾客和经营升级的可玩 Toy。

## 玩法

- 服务随机进店的小动物客人
- 按订单从货架拿取猫爪拿铁、奶油鱼丸面和月光小饼干
- 通过结账获得营业额和小费
- 缺货时补货，赚到现金后升级咖啡机和货架
- 应对暴雨夜、赶工潮和午夜电波等特殊事件
- 在 3 分钟夜班结束后查看营业评价

## 本地运行

```bash
node server.cjs
```

浏览器打开 `http://localhost:4173`。
